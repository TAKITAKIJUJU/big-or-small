# USOTUKI — ハンカチ落とし計時器

**公開版：https://usotuki.app/**

本物のハンカチと椅子を使い、同じ場所にいる2人がスマホ1台で遊ぶための日本語PWA。スマホを持つドロップ側（D）が開始・落下・チェックを記録します。チェック側（C）は前向きに座り、スマホを操作しません。

1ターン60秒。蓄積・消化済み・ペナルティ内訳を分離し、累計臨死時間（蓄積＋消化済み）が300秒以上になると敗北。毎ターン交代し、強制インターバルも自動開始もありません。薬・注射・蘇生の動作は行いません。

## 使い方

1. 「新しい試合」で名前と最初のD、スマホを持つ手を選ぶ。
2. 時報を試聴し、端末の音量を確認する。
3. 両者の準備ができたら「カウント開始」。即計測を開始する。
4. Dがハンカチを落とした瞬間に「落下」、Cが振り向いた瞬間に「チェック」を押す。
5. 結果を確認し、次のDが好きなタイミングで次ターンを始める。

タップの音と振動はありません。物理的な出来事からDの反応までの遅れはなくせないため、両者の合意で使用してください。

## 保存・オフライン

- 試合は端末のIndexedDBだけに保存。ログイン、外部API、バックエンド、広告、トラッキング、オンライン対戦は使いません。
- 全ターン履歴、計算根拠、A/Bの推移グラフ、過去試合を閲覧できます。
- 誤操作は「直前ターンを無効化・再プレイ」。両者確認と理由を必要とし、旧記録も監査履歴に残します。
- JSON／CSVを書き出せます。削除には確認が必要。新規試合で古い試合を上書きしません。
- 一度オンラインで読み込み、設定の「オフライン準備完了」を確認してください。Chromeのメニューからホーム画面に追加できます。以後は通信なしで起動・計測・時報・履歴が使えます。
- Service Worker更新は進行中の画面を強制再読込しません。全タブを閉じ、次に起動した時に新バージョンが反映されます。
- 保存失敗は未保存を表示して進行を止めます。JSONを書き出すか、保存を再試行してください。ブラウザのデータ消去で記録も消えます。

## 計時と音の限界

経過時間はperformance.now()の差分を整数ミリ秒で判定。表示用のタイマー回数は加算しません。60.000秒以降の操作は時間切れを優先します。画面を隠す、ロック、再読込、終了した場合は、そのターンを無効にして確定済みの記録から再開します。

v1.3の時報は、実時刻の1秒ごとに「チッ」、10秒ごとに「ポーン」。毎分57・58・59秒には「ピッ」の予告音が入り、00秒を区別できます。ターン開始から60秒後とは連動しません。00・10・20・30・40・50秒の7秒前から、次の時刻を内蔵の女性音声で予告します。例えば08:08:53に「午前8時9分ちょうどをお知らせします」と案内し、08:09:00が長音です。音と声はオフライン対応。原作や電話サービスの録音は使わず、波形と読み上げ音源を生成しています。

v1.3.1から自動の時報は対戦画面を開いている間だけ鳴ります。ホーム・準備・設定・履歴では試聴を押した時だけ再生。画面を移動すると、鳴っている音と予約済みの音を止めます。試聴を終えてもホームで時報が始まることはありません。

試聴は独立した約12秒のサンプル（「午前8時8分」）で、時報OFFでも再生できます。試聴中は通常の時報を休止し、停止ボタンでも中止できます。時報はWeb Audioを優先し、利用できなければ準備済みのHTML Audioで再生します。初期音量80%、保存済みの音量と時報ON/OFFは保持。旧チャイムからの移行時には声をONにし、以後は声のOFF設定も保存します。毎ターンの開始操作で代替音声の再生許可を確認し直します。AudioContextが終了状態なら作り直し、必要な場合だけ時報の予約を同期し直します。計測の開始時刻を音声準備で待たせません。再生中・再生拒否・音量0%を画面に表示しますが、実際に聞こえるかは端末のメディア音量と試聴で確認してください。端末の音量・マナーモード・ブラウザ制限・処理遅延に左右されるため、厳密な音の同期を保証しません。Android実機未検証。

v1.1は白地に濃い文字と青の操作ボタン。計測中は残り時間・落下・チェックを中心に表示し、結果は次の開始操作より前に確認できます。

## 開発と検査

Node.js 22.12以上（開発環境24）。

```sh
npm ci
npm run dev
npm run typecheck
npm run lint
npm test
npm run build
npm run test:e2e
```

配信物はdist/。build時に資産一覧からバージョン付きService Workerを生成します。ローカルでPWAを試す場合は `npm run build && npm run preview`。Playwrightは配信用ビルドを4174で起動します。環境のChromiumは `/usr/bin/chromium`、他環境ではplaywright.config.tsの実行パスを合わせてください。

## 公開

公開先／既存ドメインは https://usotuki.app/ 。既存Cloudflare Worker「usotuki」の静的配信を使用できます。アプリの記録は配信サーバーへ送信しません。最新の公開状態・コミット・検証結果は [docs/deployment.md](docs/deployment.md) とdeployment/production.jsonを参照してください。
