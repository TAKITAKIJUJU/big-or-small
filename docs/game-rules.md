# ゲームのルール

2026-11-14更新。新規対戦は `open`。抽選先行、全回有効スタック、同数時の参加料持ち越しを採用する。

## 基本と進行

各自1〜13を一枚ずつ、300チップで開始。最大13回。先手は奇数回が人間、偶数回がNPC。

参加料を出す → BIG／SMALLを独立50%ずつで公開 → 両者が札を裏向きで確定 → ベッティング → 公開またはフォールド → 精算。

抽選は一度だけ。選札後の再抽選、伏せた札の交換はできない。NPCも公開された条件を見て、人間の確定札を知らずに選ぶ。BIGは大きい数字、SMALLは小さい数字の勝ち。カードは一度使ったら戻らない。フォールドでは両者の札を非公開で使い終える。

## 参加料と上限

各回の規定参加料は `2, 4, 6, 8, 10, 14, 18, 24, 30, 40, 50, 64, 80`。両者同額で、勝敗に応じた補正はしない。

全回の追加ベット上限は有効スタック、つまり `min(人間の残チップ＋今回の追加拠出, NPCの残チップ＋今回の追加拠出)`。初回は参加料2を払った後の298まで。サイドポットは作らず、相手が合わせられない額は要求しない。

規定参加料に足りない場合は `min(規定額, 両者の残額)` を双方が出す。例：規定40、人間25、NPC575なら双方25を払う。抽選を公開し、双方が選札したところで追加ベットなしの公開へ進む。

## ベッティング

参加料は追加ベットに含めない。BET／RAISEの `total` は行動後の追加拠出合計、`paid` は今払う差額。

- CHECK：追加拠出に差がない場合のみ。双方チェックで公開。先にチェックした側も後のベットへ応答できる。
- BET：新たに賭け始める。
- CALL：相手との追加拠出の差額を払い、公開する。
- RAISE：相手の追加合計に原則2以上を上乗せ。双方合わせて2回まで。最初のBETは数えない。
- FOLD：賭けに直面したとき降りる。未コール差額を返し、残るポットを相手へ渡す。

原則2刻み。有効スタックの端数だけ1チップの増額も認める。合法手はエンジンの `getLegalActions` で共通に検証する。

「最小・半分・最大」は額を選ぶ操作。ベット／レイズを押すまで確定しない。条件付きの損益は今回の開始時から計算し、勝った場合には以前からの持越ポットも全額含める。相手が降りた場合には未コール分が返るので、表示の損益とは異なる。

## 同数と持ち越し

同数なら、その回の追加ベットを双方へ全額返還する。参加料と以前からの持越ポットは中央に残し、次の回で勝った側が取得する。双方のカードは公開して使い終える。

例：初回に13対13、追加298ずつを出した場合、298ずつを返し、残チップは298対298、中央に4。次の参加料4ずつを加え、次回はポット12から始まる。次も同数なら追加分だけを返し、12をさらに持ち越す。

13回目の同数、または追加分を返した後もどちらかの残チップが0の場合、持越予定のポットはその場で折半する。折半後にまだ次の回へ参加できるなら続ける。最終的な0チップ・13回終了の判定は返還と分配を終えてから行う。持越分で双方の資金が枯渇する場合も、資金を残したまま停止しない。

常に `人間チップ＋NPCチップ＋中央ポット = 600`。持越ポットは中央ポットの内数であり、重ねて加算しない。進行中は `pot = carryPot + 参加料×2 + 両者の追加拠出`、精算後に残せるのは持越分のみ。対戦終了時は中央0にする。

## 終了・公開・保存

精算後にどちらかが0、または13回を終えたら、残チップの多い方が勝利。同額は引き分け。

人間の伏せ札や非公開廃棄札をNPCへ渡さない。対戦中は3D・DOM・履歴でも相手のFOLD札を非公開にする。終了後の開示設定ONでのみ全札とNPCの判断記録を表示する。

以前の保存試合は当時のルールで再開する。

- `classic`／指定なし：抽選は選札後、固定参加料2、追加上限20（当時の全額ONなら上限なし）、次の2を払えなければ終了。同数は分配。
- `pressure`：抽選は選札後、参加料と上限が増える、当時の全額設定を維持。同数は分配。
- `open`：今回の新ルール。設定の旧allIn値にかかわらず全回有効スタック。新規対戦は必ずこちらを記録する。

保存ログの抽選値から再生するので、再読込で条件は変わらない。
