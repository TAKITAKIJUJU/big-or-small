# ゲームのルール

2026-11-14更新。新しい対戦は参加料・追加上限が上がるルール。公開済みの旧セーブは固定参加料のまま再開する。

## 基本と進行

1〜13のカードを1枚ずつ持ち、各300チップで開始。最大13ラウンド。各回の参加料は中央ポットに入り、勝者が受け取る。先手は奇数回が人間、偶数回がNPC。

参加料を出す → 両者が1枚ずつ裏向きで確定 → BIG/SMALLを独立した50%ずつで抽選 → ベッティング → 公開またはフォールド → 精算。

カードは一度だけ。BIGは大きい数字、SMALLは小さい数字の勝ち。同数ならポットを半分ずつ。フォールドでは両者のカードを非公開で使い終える。参加料や上限を、チップ差や勝敗に応じて変更する補正はない。

初期の調整値。参加料を上げるだけでなく、賭けられる上限も広げ、後半の一勝が大きく動くようにする。金額は `src/game/stakes.ts` の公開された固定表から取り、UIとNPCとエンジンで共用する。

「全ラウンドで全額勝負」をONにすると、最初から追加上限が有効スタックとなる。OFFでも最終回は有効スタックまで賭けられる。

### 参加料不足の最後の勝負

新ルールでは参加料に足りなくても即終了しない。実際の参加料は `min(規定参加料, 人間の残額, NPCの残額)` を双方が同額ずつ払う。サイドポットや片側だけ高い参加料はない。

例：規定40、人間25、NPC575なら双方25を払う。ポット50、残り0対550。双方が札を確定し抽選したあと、追加ベットなしで公開する。人間が勝てば50対550で続けられ、負ければ0対600で終了。同数なら25ずつ戻る。少ない残額が奇数でもポットは必ず偶数。

精算後にどちらかが0なら終了。13回を終えた場合も終了し、所持チップが多い方が勝ち。同数は引き分け。

## ベッティング

参加料は追加拠出に含めない。`contributions[p]` はそのラウンドの追加拠出合計、BET/RAISEの `total` は行動後の合計、`paid` は今払う差額。ポットには参加料と追加拠出のすべてが含まれる。常に `chips.human + chips.bot + pot = 600`。

- CHECK：追加拠出の差がない場合のみ。双方CHECKで公開。最初にCHECKした人も、その後のBETへ応答できる。
- BET：新しく賭け始める。追加合計を指定する。
- CALL：相手の追加合計との差額を払う。自分4、相手10なら追加6。合計が揃ったら即公開。
- RAISE：相手の額より原則2以上高い合計へ上げる。双方合わせて2回まで。最初のBETは数えない。
- FOLD：相手の賭けに直面しているときに降りる。未コール差額を先に返し、勝者へ残りのポットを渡す。

追加額は原則2刻み。すべて `getLegalActions` の列挙から選ぶ。

有効上限は `min(今回の追加上限, 人間の残チップ+追加拠出, NPCの残チップ+追加拠出)`。上限なしはInfinityとして扱う。相手が受けられない額は合法手に出さない。残額を使い切る端数のみ1刻みや1チップの最終レイズも認める（レイズ2回上限は維持）。

片側がBETで全額を出しても相手のCALL/FOLDを待つ。CALLで同額を出し終えたら自動で公開する。FOLD時の差額返還は全ラウンドで同じ。

例：人間6 → NPCが14へレイズ → 人間FOLD。未コール8をNPCへ戻し、ポットは参加料×2＋12。NPCがこれを取得する。

## 一回の勝負での逆転例

第10回の開始時が人間160対NPC440。参加料40を払い、残り120対400、ポット80。双方が追加120を出すと総ポット320。人間が勝てば320対280へ逆転する。負ければ0対600。参加料と追加拠出の合計160が、その勝負での損益となる。

増えるのは賭け金であり、隠れた逆転倍率、後出しの札交換、勝敗に応じた抽選補正、NPCだけのボーナスはない。残40対560のような大差から一度で必ず逆転できる仕組みではなく、再起には複数回の勝利が必要な場合もある。

画面の「最小・半分・最大」は額を選ぶ操作。ベット／レイズを押すまで確定しない。「この額で双方が勝負したら」の損益は参加料を含めたラウンド全体の数値。相手がFOLDした場合は、未コール分を返すのでこの表示額とは異なる。

## 情報公開とNPC

NPCは自分の手札・公開履歴・現在の抽選・所持チップ・合法手だけで判断する。選札は抽選前。人間の伏せ札や非公開廃棄札は渡さない。後半の上限や参加料も公開情報として両者に同じものを渡す。

対戦中の相手のFOLD札は3D・DOM・履歴とも非公開。試合終了後にだけ、設定に従って履歴で開示する（初期ON）。

## 旧セーブとの互換性

`Session.ruleset` がない既存の記録は `classic` で再生し、固定参加料2・追加上限20（旧オールインONなら有効スタック）・次の参加料2を払えなければ終了、を維持する。新しい対戦は `pressure` を明記して保存する。旧試合を新しい金額で再計算しない。旧ルール再開中は画面にも明記する。
