# 時間モデルと判定

ruleVersion: handkerchief-1。全て整数ミリ秒。

| 値 | 意味 |
|---|---|
| currentAccumulatedMs | チェック成功で蓄積した未消化時間（座視の際） |
| consumedMs | 失敗時に既存蓄積＋60000を移した累計 |
| penaltyLifetimeMs | 過去の60000ペナルティだけの内訳。consumedMsに既に含む |
| 累計臨死時間 | consumedMs + currentAccumulatedMs |
| 残り | max(0, 300000 − 累計臨死時間) |

成功はdrop < check < 60000の場合のみ。差分check−dropをCの蓄積へ加える。成功して300000に達してもその時点で敗北し、架空の消化はしない。

落下前・同値のチェックはC失敗。ペナルティ内訳に60000、消化済みにその時点の蓄積＋60000を加え、蓄積を0にする。例：蓄積90000→失敗で消化150000、ペナルティ60000、蓄積0、累計150000。

60000以降の操作は受理しない。落下がなければDだけ、落下済みならCだけに60000ペナルティと蓄積の消化。DもCも未操作の場合に両者へ課さない。59.50秒落下・59.90秒チェックは400ms成功、チェックなしのまま60秒はC失敗で60000、500msの成功を作らない。

消化100000＋蓄積200000で敗北。蓄積200000を根拠なく消化済みへ移して重複計上しない。

確定ターンだけでD/Cを交代。中断は役割・集計を変えずやり直す。直前無効化は理由と両者確認を必要とし、元の入力と無効化イベントを追記保存して再計算する。終了した試合の直前記録も無効化でき、終了判定と役割も再計算する。

原作の蓄積メーター・消化・毎分時報を参考にする。原作の蓄積5分での全量注入と本アプリの過去の消化済みを含む累計5分敗北は別。累計での即敗北、時間切れペナルティ、ターン無制限、中断無効は独自の変更。現実には時間を管理するだけで薬・注射等の動作はしない。
