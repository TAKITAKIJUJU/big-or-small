# ゲームのルール

## 進行

各自1〜13の札を1枚ずつ持ち、チップ300ずつで開始。各ラウンドの先頭で双方2を支払い、ポット4。先手は奇数ラウンドが人間、偶数がBot。

両者の選札が確定するまで抽選不可。Botの選札は人間の操作前に、そのBotのPlayerViewから決める。確定後は変更不可。抽選は毎回新しい乱数を1回だけ使い、`roll < 0.5` がBIG、それ以外がSMALL。試合全体の個数調整はしない。

BIGは大きい札、SMALLは小さい札が勝つ。ベッティング完了後のみショーダウン。CHECK→CHECK、またはCALLで即座に完了。FOLDでは両札を非公開で廃棄。双方の札を使用済みとして取り除く。13回終了後、または次のアンティ2を片方でも払えない場合に終了し、残チップで勝敗。同数は引き分け。

## 金額の定義

アンティは「追加拠出」に含めない。`contributions[p]` はそのラウンドの追加拠出合計、`action.total` はBET/RAISE後の追加拠出合計、`paid` は今払う差額。`pot` はアンティと追加拠出の全額を既に含む。常に `chips.human + chips.bot + pot = 600`。追加拠出をもう一度足さない。

- CHECK：未コール額が0の場合のみ。最初のチェック後も相手のベットに応答できる。
- BET：現在の追加拠出目標が0の場合、2刻みの総額を指定。
- CALL：相手の合計との差額を払う。例：自分4、相手10なら追加6。
- RAISE：現在の目標より原則2以上高い総額を指定。BETはレイズ回数に数えず、両者合わせてRAISEは2回まで。
- FOLD：相手の賭けに直面している場合のみ。双方の追加拠出差額を返してから勝者へ精算。

通常は1人の追加拠出合計20まで。BET/RAISEは `getLegalActions` が列挙する実際のコマンドからのみ選ぶ。

例：人間6 → Botが合計14へレイズ → 人間FOLD。Botへ未コール差額8を戻し、ポットはアンティ4＋双方6＝16。Botが16を取得。人間は合計8を失い、Botは8増える。

## オールイン（初期OFF）

20上限を外すが、常に両者が支払える有効額以下に制限する。サイドポットなし。

`有効上限 = min(人間の残チップ + 人間の追加拠出, Botの残チップ + Botの追加拠出)`。通常モードはこの値と20の小さい方。

- アンティ後に人間98、Bot14なら、追加拠出の総額は双方最大14。人間が98を一方的に出すコマンドは合法手に存在せず拒否。
- 人間5、Bot591なら総額2/4/5が合法。5のみ端数オールインとして例外。総額4に対し総額5へのレイズも有効額を使い切る例外。レイズ回数上限は維持。
- 人間が4を拠出し、Botが5へ上げたら、人間は追加1をCALLできる。1チップの例外は端数有効額に合わせるためだけ。
- 片側が残0になったBETであっても、相手のCALL/FOLDを待つ。CALLで合計が一致すると即時ショーダウン。
- アンティ後に片側の残が0なら、双方選札・抽選後に追加ベットなしでショーダウン。
- FOLD時は常に未コール差額を返還。同額CALL後のポットは `4 + 2 × 追加拠出` なので偶数。引き分けの配当は必ず整数。

## 情報公開

対局中の自分の札は本人に見える。相手の選札は選択済みフラグのみ。相手の非公開使用済み札や残り手札の一覧はPlayerViewに入れない。フォールド札は3D・DOM・履歴で裏のまま。試合終了後は設定「全カードを開示」（初期ON）に従って履歴でのみ開示。

Botの確率推定は、公開された使用済み札を1〜13から除く。秘密の廃棄札は候補に残す。推定は完全情報の勝率ではない。
