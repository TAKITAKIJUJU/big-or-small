## 最終ローカル結果

型チェック・Lint・ビルド成功。単体36件、配信用ビルドのブラウザ11件すべて成功（28.3秒）。320×568／360×640／390×844／430×844で左右配置と巨大ボタンの画面内位置を確認。ネット遮断後の再起動、計測、履歴、時報試聴操作も成功。保存不能・容量不足・同時タブの上書き拒否を含む。

初回のオフライン読込は静的キャッシュのVaryヘッダー差でJS/CSSが一致せず失敗。ビルド時に確定した静的資産だけをキャッシュする前提でignoreVaryを設定し、修正後の11件が成功した。厳密な採時検査ではブラウザの時計を明示的に停止してから進め、検査操作自身の経過を混ぜない。競合タブは即中断するため、一時的な計測画面の表示ではなく上書き拒否と元の記録保持を検査する。

Android実機未検証。チャイムの実際の聴取、音量、ロック時のOS挙動、端末でのインストールは実機確認が残る。
