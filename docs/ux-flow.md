# 画面と操作

1. ホーム：3Dの部屋と卓、USOTUKIロゴ、対戦開始、保存試合の再開、遊び方、設定。
2. 選札：3Dの手元の札をタップすると持ち上がる。画面下の横スクロールの数字ボタンも同じ選択状態に結びつく。13枚を極小に重ねない。最後に「Nの札を伏せる」を押して確定。
3. 抽選：双方の札を伏せてから、エンジンが確定したBIG/SMALLを表示。手元の札はHUDでも本人だけ確認できる。
4. ベッティング：手番、追加拠出、ポット、上下額を表示。±ボタン・スライダーは合法な合計額を選ぶ。ボタンには「追加N → 合計M」を明記。誤操作を防ぐ短い同期ロック。
5. 決着：公開なら3Dで札が返る。フォールドなら裏のまま。チップ増減とポットを表示し、次ラウンドは明示操作。
6. 結果：残チップ、勝敗、経過回数、再戦、履歴とブラフの振り返り。

初回は下部パネルに実操作に沿う説明を出す。モーダルで操作を遮らず、選札→抽選→賭け→決着まで案内。スキップと設定からの再表示あり。

設定・ルール・履歴はnative dialog。背面はinert、Esc/閉じるで戻り、フォーカスはブラウザが復帰。設定・履歴表示中とホームではBotタイマーを止める。ルールの?ボタンから用語を読める。

カメラは着席視点。縦画面ではFOVを広げ、見下ろしすぎない配置。決着時に小さく中央へ寄る。スキップで視点を安定させ、Bot思考・抽選も進められる。Reduced Motionでは移動を即時化し、CSSの点滅・回転も停止。

DPRは最大1.5、低品質は1。自動画質では起動直後を除く遅いフレームを検知し、影と解像度を下げる。`prefers-reduced-motion` を初期状態と変化に反映。WebGL2非対応、初期化例外、context lostでは同じエンジンを使う軽量卓へ切替。選札・ベット・結果は全てDOMから操作できる。GPU復旧待ちで対局を失わない。

safe-areaとsvhを使用。小画面は必要時にページが縦にスクロールできる最小高を設け、操作を到達不能にしない。色だけではなく文字、数値、状態で伝える。音は初回操作後のみ。ミュートは常にヘッダーで操作可能。
