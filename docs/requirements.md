# 要件

2026-11-15。ユーザー添付のusotuki_handkerchief_codex_master_prompt.txtを最新仕様とする。

人間2人・実物の椅子とハンカチ・Androidスマホ1台。Dが片手で開始／落下／チェックを記録する計器。相手の物理動作の自動検出はしない。

- 1ターン60秒。ターン数無制限、D/C交代、強制の待機・自動開始なし。
- 整数msの蓄積／消化済み／ペナルティ内訳、蓄積＋消化済み300秒以上で敗北。二重加算を禁止。
- 成功は落下より厳密に後で60秒未満のチェック。前・同時はC失敗。60秒時点で未落下はDだけ、落下済み未チェックはCだけにペナルティ。
- 最新の参考画像に合わせ、実時刻の毎秒に秒音、10秒ごとに長音。57・58・59秒に予告音を入れ、00秒を区別する。00・10・20・30・40・50秒の7秒前から内蔵女性音声で時刻を予告。音源は独自生成し、原作や電話サービスの録音は使わない。操作は無音・無振動。音声の不具合で計測を停止しない。
- IndexedDBに全試合・追記履歴、前ターン無効化の理由と監査、JSON／CSV書出、確認付き削除。
- 非表示・ロック・離脱・再読込で正確な継続を装わず中断無効化。Wake Lockは対応時のみ。
- manifest／資産キャッシュ／Service WorkerでPWAとオフライン。更新が計測中にリロードしない。
- 左右手の配置、320〜430px、横画面・PC、フォーカスと読み上げラベル、Reduced Motion。WebGLなし。
- 外部API・ログイン・サーバー送信・追跡なし。React以外の旧3D依存を撤去。
- 最新の視認性改善依頼を優先し、白地・濃い文字・青の操作ボタン。主要文字とボタンのコントラスト比4.5以上。計測中の情報を絞り、結果を次の開始前に表示。漫画の画像、ロゴ、人物、フォントは使用しない。
- 試聴は時報OFFでも停止させず、通常時報と重ならない独立した約12秒のサンプル。再生中・再生拒否と停止ボタンを表示。音量0%は試聴前に知らせる。既存の音量・時報ON/OFFを保持し、新時報へ移行する初回だけ読み上げをONにする。端末での聴取確認と再生処理の成功を区別する。

原作参考の発想と独自ルールをルール画面に分けて記載。薬・注射・蘇生は行わない。人間の反応遅れ、音の同期、端末制限を表示。Android実機の未検証を明記する。

- ターン交代後も時報を継続し、各ターンの開始操作で代替音声を再準備。終了したAudioContextを再作成し、復帰時には時報予約を再同期する。実機で報告された停止現象そのものはブラウザ検査だけで再現済みとしない。
- 自動の時報は対戦画面内だけで動作。ホーム・準備・設定・履歴では試聴の明示操作時だけ再生し、画面移動で再生中・予約中の音を止める。停止した試聴が非同期処理の完了後に再開しないこと。


最新仕様 v1.4：実時計への同期を廃止。ターン開始を0秒にし、計時と同じperformance.nowの起点で10秒ごとの音と女性音声の経過予告を予約する。57・58・59秒は予告音、60秒は長音。早期終了・中断で停止し、60秒時間切れの長音は余韻まで再生。次ターンは0秒から。ホーム・待機中は自動で鳴らさない。端末時刻の変更は計測・音へ影響しない。厳密なスピーカーの同期は端末制約がある。


最新 v1.5：開始前に3秒の取り消し可能なカウントダウン。カウントダウン中は落下・チェックを受け付けず、画面移動も禁止。非表示・離脱・再読込なら計測を開始せず待機へ。performance.nowの締切をTurnClock.startへ渡し、計測と音の0秒を揃える。開始前には試合のactive markerを保存せず、判定・ペナルティを生成しない。画面点灯維持はカウントダウン中から要求する。


v1.5.1：開始前の3・2・1で短音、計測開始の締切で長音を鳴らす。開始音の予約は通常の経過音の予約と分離し、0秒での再同期が開始音を切らないようにする。取り消し・非表示・画面移動では開始音も停止。音OFF・音量0の設定は保持する。


最新 v1.5.2：女性音声の予告開始を各合図の3秒前に変更。7秒から10秒、17秒から20秒、27秒から30秒を案内する。音声は3秒以内の内蔵音源で、時報音は従来通り各10秒の基準点。開始前の3秒カウントダウン・開始音・ホームでの自動再生停止は維持。
