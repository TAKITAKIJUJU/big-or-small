# 要件

2026-11-15。ユーザー添付のusotuki_handkerchief_codex_master_prompt.txtを最新仕様とする。

人間2人・実物の椅子とハンカチ・Androidスマホ1台。Dが片手で開始／落下／チェックを記録する計器。相手の物理動作の自動検出はしない。

- 1ターン60秒。ターン数無制限、D/C交代、強制の待機・自動開始なし。
- 整数msの蓄積／消化済み／ペナルティ内訳、蓄積＋消化済み300秒以上で敗北。二重加算を禁止。
- 成功は落下より厳密に後で60秒未満のチェック。前・同時はC失敗。60秒時点で未落下はDだけ、落下済み未チェックはCだけにペナルティ。
- 現実の毎分00秒に独自チャイム。操作は無音・無振動。音声の不具合で計測を停止しない。
- IndexedDBに全試合・追記履歴、前ターン無効化の理由と監査、JSON／CSV書出、確認付き削除。
- 非表示・ロック・離脱・再読込で正確な継続を装わず中断無効化。Wake Lockは対応時のみ。
- manifest／資産キャッシュ／Service WorkerでPWAとオフライン。更新が計測中にリロードしない。
- 左右手の配置、320〜430px、横画面・PC、フォーカスと読み上げラベル、Reduced Motion。WebGLなし。
- 外部API・ログイン・サーバー送信・追跡なし。React以外の旧3D依存を撤去。
- オリジナルの黒・金属ゴールド・アンバーの計器。漫画の画像、ロゴ、人物、フォントは使用しない。

原作参考の発想と独自ルールをルール画面に分けて記載。薬・注射・蘇生は行わない。人間の反応遅れ、音の同期、端末制限を表示。Android実機の未検証を明記する。
