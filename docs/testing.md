## 性能の実測と限界

最終の高画質測定（390×844px、DPR1、SwiftShader）:

- DOMで札を選んで次のrequestAnimationFrameまで：95.3 / 200.7 / 173.1 / 196.3 / 179.9ms。
- ウォームアップ後34区間のフレーム間隔：中央値150.1ms、p95 283.4ms。
- ブラウザ標準のINP測定ではなく、ソフトウェア描画環境内の参考値。
- この環境では高画質が重い。実GPUを備えるAndroidの速度へ換算しない。30fps達成を主張しない。

自動画質はCPUコア数に加え、起動直後を除く連続12フレームの平均が45msを超える場合に低へ下げる。低品質ではDPR1と影なし。起動時から低品質ならアンチエイリアスもOFF。品質を上げるか下げるかは設定でも選べる。背景タブや大きな休止時間を性能サンプルに使わない。

チップスタックはインスタンス描画で1山2draw calls。重い物理やポスト処理なし。Three.js/R3Fチャンクは943.46KB、gzip254.03KB。メインJSは約245KB、gzip77KB、シーンJSは約17KB、gzip6KB、CSSはgzip約3.7KB。テクスチャとモデルは手続き生成。3Dは別チャンクへ分割し、読み込み表示を設ける。

画像・測定JSONは `test-results/` に出力（Git対象外）。保存用の画像・配信ZIPは `/workspace/artifacts/usotuki/portrait-redesign/` にまとめる。
