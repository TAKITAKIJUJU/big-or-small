# 構成と信頼性

- domain/game.ts：副作用のない整数ms判定、追記イベントからの全履歴再計算、直前無効化。
- application/clock.ts：注入可能な単調時計・壁時計・ID。開始／落下／チェック／時間切れ／中断の同期ガード。確定前にliveを消すことで二重処理を防ぐ。
- application/useInstrument.ts：Reactへの反映、IndexedDB書込キュー、復元、音声、Wake Lock。経過表示は時計の差分を読み、intervalの回数を加算しない。
- storage/db.ts：バージョン1 IndexedDB。matchesとsettings。試合revisionの楽観ロックで別タブの上書きを拒否。保存失敗は未保存を表示して進行停止、再試行とJSON書出を提供。
- audio/chime.ts：実時刻の次の毎分境界の計画、時計変更・復帰の再同期、過去の音を再生しない処理、独自音のWeb Audio予約。音声はローカルの日本語音声があるときだけ。
- ui/components.tsx：4値を分離したゲージ、60秒計器、履歴の計算根拠、SVG推移図。
- App.tsx：ホーム、準備、待機、計測、結果、全履歴、過去試合、設定、ルール。記録ボタンはpointerdownで採時、キーボードclickも対応。計測中はナビゲーション禁止。
- scripts/service-worker.mjs：ビルド資産からバージョンを作り、初回一括キャッシュ。skipWaitingなしで既存画面を強制更新しない。

集計値のスナップショットは保存せず、確定入力から常に導く。ペナルティの内訳を累計へ再加算する余地を避ける。表示側は試合オブジェクトが変わるときだけ再集計する。無効化された入力も削除しない。

計測開始前にactive markerを保存し、計測完了時に確定結果へ置換。中断時の書込がタブ終了に間に合わなくても、次回読み込み時にactive markerを中断イベントへ変換する。異なるページ間のperformance.nowを接続しない。確定済みターンは復元できる。

書込失敗時の結果はメモリに残すが未保存として表示し、次の計測を禁止する。JSON書出または保存再試行が必要。黙って保存できた表示にしない。新しい試合で過去試合を削除しない。

外部フォント、画像API、分析、認証、DBサービス、オンライン対戦は使用しない。試合データのネットワーク送信はない。旧アプリのブラウザ保存領域と今回のIndexedDBは独立し、旧領域は勝手に削除しない。
