# 構成と信頼性

- domain/game.ts：副作用のない整数ms判定、追記イベントからの全履歴再計算、直前無効化。
- application/clock.ts：注入可能な単調時計・壁時計・ID。開始／落下／チェック／時間切れ／中断の同期ガード。確定前にliveを消すことで二重処理を防ぐ。
- application/useInstrument.ts：Reactへの反映、IndexedDB書込キュー、復元、音声、Wake Lock。経過表示は時計の差分を読み、intervalの回数を加算しない。
- 自動時報の稼働可否はAppの対戦画面状態からuseInstrumentへ渡す。対戦画面以外では時報スケジューラを起動せず、画面移動時に再生中・予約中の全音声を取り消す。試聴は世代番号で非同期の再生完了・拒否を確認し、取り消した試聴が代替合成音で再開しないようにする。
- storage/db.ts：バージョン1 IndexedDB。matchesとsettings。試合revisionの楽観ロックで別タブの上書きを拒否。保存失敗は未保存を表示して進行停止、再試行とJSON書出を提供。
- audio/signal.ts：壁時計の各秒を1秒先まで予約し、毎秒音・57/58/59秒の予告・10秒ごとの長音、03/13/23/33/43/53秒から次の10秒境界の読み上げを計画。時計変更・復帰は再同期し、過去の音をまとめて鳴らさない。
- audio/chime.ts：Web Audioで音と内蔵音声を予約。利用できない場合はHTML Audioへ切り替える。voice-index.jsonの区間を使い、時・分・秒の音声を連結する。音声データを一度だけ読み込み、Web AudioのデコードとHTML AudioのローカルBlobで共有。初回のCDN応答がRange非対応でも、Blobのメタデータを待って正しい区間へシークできる。取消世代を確認し、非同期の読込完了が取消後に古い音を鳴らさない。試聴は別の音声ファイル・音声ノード・予約を持ち、通常時報を一時休止。設定OFFは通常予約だけ、非表示は全てを止める。音声拒否は画面へ伝える。端末のspeechSynthesisや外部TTSには依存しない。ターン開始操作で毎回新しい代替音声を無音準備し、現在の長音が終了するまでは前の再生器も保持する。再準備に失敗した時は古い許可フラグを消す。終了状態のAudioContextは再作成し、再開・作成時だけ時報予約を同期し直す。
- scripts/generate-audio.py：開発時だけOpen JTalkとMMDAgent Meiの女性音声で90区間を生成し、波形合成の秒音・予告音・長音と試聴音源を出力。生成物だけを配信し、エンジンや音声モデルは同梱しない。音声の出典・ライセンス・加工内容はaudio-attribution.txtとlicenses.txtに収録。
- ui/components.tsx：4値を分離したゲージ、60秒計器、履歴の計算根拠、SVG推移図。
- App.tsx：ホーム、準備、待機、計測、結果、全履歴、過去試合、設定、ルール。白地と濃い文字を使い、計測中は詳細集計を隠す。前ターン結果は次の開始ボタンより前。記録ボタンはpointerdownで採時、キーボードclickも対応。計測中はナビゲーション禁止。
- scripts/service-worker.mjs：ビルド資産からバージョンを作り、初回一括キャッシュ。skipWaitingなしで既存画面を強制更新しない。キャッシュしたMP3/WAVへのRange要求は該当バイトを206で返し、通信なしでも音声区間へシークできる。範囲外は416。

集計値のスナップショットは保存せず、確定入力から常に導く。ペナルティの内訳を累計へ再加算する余地を避ける。表示側は試合オブジェクトが変わるときだけ再集計する。無効化された入力も削除しない。

計測開始前にactive markerを保存し、計測完了時に確定結果へ置換。中断時の書込がタブ終了に間に合わなくても、次回読み込み時にactive markerを中断イベントへ変換する。異なるページ間のperformance.nowを接続しない。確定済みターンは復元できる。

書込失敗時の結果はメモリに残すが未保存として表示し、次の計測を禁止する。JSON書出または保存再試行が必要。黙って保存できた表示にしない。新しい試合で過去試合を削除しない。

外部フォント、画像API、分析、認証、DBサービス、オンライン対戦は使用しない。試合データのネットワーク送信はない。旧アプリのブラウザ保存領域と今回のIndexedDBは独立し、旧領域は勝手に削除しない。


最新仕様 v1.4：実時計への同期を廃止。ターン開始を0秒にし、計時と同じperformance.nowの起点で10秒ごとの音と女性音声の経過予告を予約する。57・58・59秒は予告音、60秒は長音。早期終了・中断で停止し、60秒時間切れの長音は余韻まで再生。次ターンは0秒から。ホーム・待機中は自動で鳴らさない。端末時刻の変更は計測・音へ影響しない。厳密なスピーカーの同期は端末制約がある。


最新 v1.5：開始前に3秒の取り消し可能なカウントダウン。カウントダウン中は落下・チェックを受け付けず、画面移動も禁止。非表示・離脱・再読込なら計測を開始せず待機へ。performance.nowの締切をTurnClock.startへ渡し、計測と音の0秒を揃える。開始前には試合のactive markerを保存せず、判定・ペナルティを生成しない。画面点灯維持はカウントダウン中から要求する。
