# 参加料と逆転幅の調整

2026-11-14の追加採用：新規対戦はopen。BIG／SMALLを選札前に公開、全回有効スタックまで、同数は追加分返還・参加料持越（最終回・続行不能時は折半）。旧試合のルールは再開時に維持。現在の定義はgame-rules.mdを優先する。

## 改修の理由

初版は全13回の参加料が2、追加上限20。1回で動く差額は最大22で、終盤に大差をつけられると強いカードが残っていても取り戻しにくかった。

新しい対戦では参加料2〜80、追加上限20〜240、最終回は有効スタックとする。前半の小さい勝負と、後半の大きな勝負を区別する。札を温存する価値と、フォールドして失う参加料の重さが増す。

参加料不足を即終了にすると、逆転の勝負そのものがなくなる。そのため残額に合わせた同額参加で一枚の勝負を残す。参加料は徴収して消すお金ではなく、勝者が獲得するポットへの拠出。

## 数値の意味

同じチップ数から始めても後半の結果で順位が入れ替わる。160対440から320対280の逆転は、合法コマンドだけの記録を生成して単体・ブラウザ検査する。倍率を追加せず、常に600チップを保つ。

最大の損益は参加料＋双方が合わせた追加合計。弱いカードでFOLDを選ばせるブラフにも価値が生まれる一方、最大額を不用意に確定しないよう、額の選択とBET/RAISEの確定を分ける。

旧セーブは旧ルールのまま最後まで再開できる。新しいルールに切り替えるには新しい対戦を始める。

## 検証と残る調整

600試合の合法ランダム対局で上限、端数、公開情報、チップ総数、完走または0による終了を確認する。数字の面白さや難易度の均等さを数学的に保証するものではない。Android実機や継続プレイで、決着回数、早期全額勝負、フォールド率、参加料の上がり方を確認し、公開表を調整する。NPCだけの秘密の補正は使わない。
